# Alba Joyeria
---
El presente repositorio corresponde al trabajo integrador que se realiza en la materia "Taller de Programación I" de la carrera de Lic. En Sistemas de la Universidad Nacional del Nordeste.

Joyeria ALBA consiste en un sitio web desarrollado en php con el framework Laravel de PHP a través del entorno de desarrollo Laravel HERD.
Una tienda virtual que se dedica a la comercialización de joyas de diseño, que cuenta con un showroom en la ciudad de Corrientes.

Los desarrolladores del proyectyo "Joyería ALBA" somos Aguilar, Leandro Martin y Demetri, Luciana Itati.
